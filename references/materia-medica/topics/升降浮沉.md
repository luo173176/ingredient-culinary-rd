# 升降浮沉

> 来源：《中药学》第四章 中药的性能 · 第三节 升降浮沉（PDF 107–110）。
> 性质：传统中医药理论中的“作用趋向”模型。

## 一句话

升降浮沉描述药物作用于人体的四种趋向：升（向上提举）、降（向下降逆）、浮（向外发散）、沉（向内收敛）。

## 原文要点

| 编号 | 要点 | 出处 |
|---|---|---|
| E1 | “升，即上升提举，趋向于上；降，即下达降逆，趋向于下；浮，即向外发散，趋向于外；沉，向内收敛，趋向于内。” | 《中药学》PDF 107 |
| E2 | 升浮属阳，沉降属阴；病势有向上、向下、向外、向内，病位有表里上下 | 《中药学》PDF 107 |
| E3 | 影响因素：四气五味、药物质地轻重、炮制、配伍 | 《中药学》PDF 107–108 |
| E4 | 一般规律：辛甘、温热多升浮；苦酸咸、寒凉多沉降；花叶皮枝多升浮，种子果实矿物贝壳多沉降 | 《中药学》PDF 107 |
| E5 | 有例外：“诸花皆升，旋覆独降；诸子皆降，苍耳独升”；川芎、白花蛇有双向性 | 《中药学》PDF 108 |
| E6 | 炮制可改变趋向：酒制则升、姜炒则散、醋炒收敛、盐炒下行 | 《中药学》PDF 108 |
| E7 | 配伍可改变趋向：少量升浮药在大队沉降药中随之下降，反之亦然 | 《中药学》PDF 108 |

## 对食材/配伍研究的用法

`[跨来源推理]` 分析“药食同源”搭配时，可以把升降浮沉当作**传统理论中的方向性标签**，但不能当作现代药理学的作用机制。

可用句式：

```text
[原文] 生姜辛、微温，归肺、脾、胃经（《中药学》PDF 154）。
[传统理论] 辛温多升浮；但这只是传统归类，不等于现代医学的“促进循环”。
```

## 常见误用

- 把“升浮”写成“吃了会上火/血压升高”。
- 把“沉降”写成“一定通便/一定安神”。
- 只看质地，不看炮制与配伍。
- 用升降浮沉替代剂量、毒性、证候禁忌。
