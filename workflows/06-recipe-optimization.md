# 工作流 06 · 菜谱优化

## 目的

在**不改菜品身份**的前提下，用最小改动解决具体问题。

## 触发

- “这道菜太咸/太淡/太腻/太酸/太干/不香”
- “帮我优化这个配方”
- “为什么我做的和餐厅不一样”
- “减少油/盐/糖但保持好吃”

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| 原配方 | 是 | 食材、用量、步骤、温度、时间 |
| 问题 | 是 | 越具体越好 |
| 已尝试 | 否 | 避免重复建议 |
| 目标 | 否 | 更健康、更香、更嫩、更省时 |

## 诊断顺序（不要跳）

1. **配方结构**：主料/辅料/香气/酸/脂/盐比例。
2. **工艺**：切配、传热、时间、温度、静置。
3. **原料**：品种、成熟度、含水量、新鲜度。
4. **感官**：咸、酸、甜、苦、鲜、香、辣、质地。

## 优化原则

- 一次只改 1–2 个变量，保留对照。
- 先改工艺，再改配方，最后才加新调料。
- 减盐不等于加糖；可用酸、香气、鲜味、质地补偿。
- 减脂不等于加水；可用乳化、勾芡、胶质、蒸烤替代。
- 所有“更健康”结论必须有依据或标为假设。

## 质量检查

- [ ] 没有把菜改成另一道菜。
- [ ] 改动不超过 3 处。
- [ ] 每个改动有预期与风险。
- [ ] 有对照与评分表。
- [ ] 没有“加一勺神秘酱”式建议。

## 安全边界

减盐/减糖/减油涉及特殊人群时，提示不能替代医嘱；不承诺健康疗效。
