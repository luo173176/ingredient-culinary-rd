## 5. 版本限制

本书出版于 2003 年，属于历史教材：

- 食品安全标准、允许添加剂、检验方法和行业分类可能已经更新；
- 书中的营养数值、温度、保藏时限不能直接当作现行标准；
- 不能把教材描述当作法规文本或企业标准；
- 涉及现行合规与安全限值时，明确写：

> 当前十书知识库暂无充分依据。
