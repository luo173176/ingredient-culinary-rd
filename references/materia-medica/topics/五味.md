# 五味

> 来源：《中药学》第四章 中药的性能 · 第二节 五味（PDF 102–104）。
> 性质：传统中医药理论；其中“味”既指真实滋味，也指功效归纳。

## 一句话

五味是酸、苦、甘、辛、咸五种药味（另有淡、涩），既反映真实滋味，也概括药物的作用范围。

## 原文要点

| 编号 | 要点 | 出处 |
|---|---|---|
| E1 | “所谓五味，是指药物有酸、苦、甘、辛、咸不同的药味”；另有淡味、涩味，但基本仍称五味 | 《中药学》PDF 102 |
| E2 | 五味“首先是通过口尝”，但更重要的是长期临床观察总结；有时与实际口尝味道不符 | 《中药学》PDF 102 |
| E3 | 辛“能散能行”：发散、行气、行血；多用于表证、气血阻滞 | 《中药学》PDF 103 |
| E4 | 甘“能补能和能缓”：补益、和中、调和药性、缓急止痛 | 《中药学》PDF 103 |
| E5 | 酸“能收能涩”：收敛、固涩；部分酸味药生津 | 《中药学》PDF 103 |
| E6 | 苦“能泄、能燥、能坚”：清泄火热、泄降气逆、通泄大便、燥湿、坚阴 | 《中药学》PDF 103 |
| E7 | 咸“能下、能软”：泻下通便、软坚散结 | 《中药学》PDF 103 |

## 五味作用表

| 味 | 传统作用 | 常见对应 | 注意 |
|---|---|---|---|
| 辛 | 散、行 | 解表、行气、活血 | 辛散耗气，不能等同于“越多越通” |
| 甘 | 补、和、缓 | 补益、和中、缓急 | 甘腻碍胃，湿盛中满不宜 |
| 酸 | 收、涩 | 敛汗、敛肺、涩肠、固精 | 酸能收敛，外邪未解不宜过早用 |
| 苦 | 泄、燥、坚 | 清热、降逆、通便、燥湿 | 苦寒败胃，脾胃虚寒慎用 |
| 咸 | 下、软 | 泻下、软坚散结 | 咸入肾，不等于“补肾” |
| 淡 | 渗、泄 | 利水渗湿 | 淡渗伤阴，阴虚慎用 |
| 涩 | 收、涩 | 与酸相似 | 同酸，注意闭门留寇 |

## 对烹饪的用法

`[跨来源推理]` 烹饪里的“五味”与中药“五味”不是同一套体系：

- 烹饪的酸、甜、苦、咸、鲜是**感官**；
- 本草的酸、苦、甘、辛、咸是**药性归纳**，可能包含非味觉信息。

写作时必须区分：

```text
[原文·本草] 辛能散能行（《中药学》PDF 103）。
[烹饪感官] 辣椒的辣感、花椒的麻感、姜的辛香（见 DK/盐脂酸热页）。
```

不能把“辛能散”直接写成“吃辣能发汗治感冒”。

## 常见误用

- 把“甘能补”写成“甜食滋补”。
- 把“苦能燥”写成“苦瓜祛湿”。
- 把“酸能收”写成“醋能收敛毛孔”。
- 用五味替代具体成分、剂量、毒性。
