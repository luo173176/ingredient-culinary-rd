# 模块 A · 本草研究

## 范围

本模块只处理《中药学》（钟赣生主编，第4版，2016）中的内容：

- 中药基本理论：四气、五味、升降浮沉、归经、毒性、配伍、用药禁忌、炮制、剂量与用法。
- 单味药：来源、产地、采收、性状、药性、功效、应用、用法用量、使用注意、现代研究。

**不处理**：个体化处方、疾病治疗方案、药物替代、临床剂量建议。

## 入口

| 文件 | 用途 |
|---|---|
| `topics/四气.md` | 寒热温凉、程度差异、证候对应 |
| `topics/五味.md` | 辛甘酸苦咸淡、作用与禁忌 |
| `topics/升降浮沉.md` | 趋向、影响因素 |
| `topics/归经.md` | 脏腑经络定位 |
| `topics/配伍七情.md` | 相须/相使/相畏/相杀/相恶/相反/单行 |
| `topics/用药禁忌.md` | 十八反、十九畏、妊娠禁忌、证候禁忌 |
| `topics/炮制.md` | 炮制目的与常见方法 |
| `topics/毒性.md` | 毒性分级、中毒与安全 |
| `herb-index.md` | 434 条主条目全量索引（名称、功效、页） |
| `herbs/*.md` | 常用/药食同源药材的详细卡 |

## 使用顺序

1. 先判断问题属于“理论”还是“单味药”。
2. 理论问题读 `topics/`，不要只凭模型记忆。
3. 单味药问题先查 `herb-index.md`，再读 `data/herbs.jsonl` 或 `search.py --herb`。
4. 写回答时先放“传统理论”声明，再写功效与应用。
5. 涉及剂量、孕妇、儿童、慢病、西药联用：只引用原文 + 安全提示，不给建议。

## 结构化数据

`data/herbs.jsonl` 字段：

```text
name, pinyin, classical_source, nature_flavor_meridians, efficacy,
applications, usage_dosage, cautions, modern_research, chemistry,
pharmacology, adverse_reactions, pdf_start, pdf_end, confidence,
is_attached, raw_excerpt
```

`is_attached=true` 是“附药”，多为短段落，字段可能不完整。

## 安全红线

1. 传统功效 ≠ 现代医学疗效。
2. 教材剂量 ≠ 用户应吃剂量。
3. 有毒药材 ≠ 食材。
4. 孕妇/儿童/肝肾功能不全/抗凝降糖降压用药 → 先咨询医生或药师。
5. 不写“可以停药/换药/替代某西药”。

## 常见误区

- “药食同源”不是“所有中药都能长期当饭吃”。
- “性味相同”不等于“可以互换”。
- “配伍相须”不等于“现代药物协同作用”。
- “现代研究有某作用”不等于“吃它就能治病”。
