# 归经

> 来源：《中药学》第四章 中药的性能 · 第四节 归经（PDF 111–115）。
> 性质：传统中医药理论中的“作用定位”模型。

## 一句话

归经表示药物对某些脏腑经络有选择性作用，是“药物作用部位”的传统定位概念。

## 原文要点

| 编号 | 要点 | 出处 |
|---|---|---|
| E1 | “归经是药物作用的定位概念，即表示药物作用部位。归是作用的归属，经是脏腑经络的概称。” | 《中药学》PDF 111 |
| E2 | 归经指药物对某些脏腑经络有特殊亲和作用，因而对这些部位病变起主要/特殊治疗作用 | 《中药学》PDF 111 |
| E3 | 归经理论以脏腑经络学说为基础，以所治病证为依据，从疗效中归纳 | 《中药学》PDF 111 |
| E4 | 归经不同，治疗作用不同；归经指明适用范围 | 《中药学》PDF 111 |

## 结构

```text
归经 = 作用归属（归）+ 脏腑经络定位（经）
```

常见表述：

```text
辛，温。归肺、脾、胃经。
```

## 对食材研究的用法

`[跨来源推理]` 食材卡里的“归经”只能作为传统属性字段，与“适合哪类人吃”不是一回事。

正确写法：

```text
传统属性：辛，微温；归肺、脾、胃经（《中药学》PDF 154）。
边界：归经是传统理论定位，不等于现代医学的器官靶点；不能据此给个体化食疗方案。
```

## 常见误用

- 把“归脾经”写成“补脾/治脾虚”的确定结论。
- 把“归肺经”写成“治咳嗽/清肺”。
- 用归经替代辨证、剂量、配伍、禁忌。
- 把不同书的归经记载强行统一。
