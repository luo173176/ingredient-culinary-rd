## 3. 检索方法

在 Skill 根目录执行：

```bash
python scripts/search.py "淀粉 糊化 酱汁" --source MCG-V1-2013 --top 8
python scripts/search.py "果实 成熟 香气" --source MCG-V2-2013 --top 8
python scripts/search.py "肌肉 蛋白质 加热" --source MCG-V3-2013 --top 8
python scripts/search.py --page MCG-V3-2013:348
python scripts/search.py --series 食物与厨艺
python scripts/search.py --volume 3
```

推荐顺序：

1. 先用具体机制词检索，而不是只搜食材名。
2. 用 `--source` 锁定卷册，防止三册之间串页。
3. 用 `--page` 打开整页，核对 OCR 上下文。
4. 把可读音的短句作为引文；数字、温度和单位必须回看原页。

## 4. 与其他来源的组合

- 与 `FC-BELITZ-2009`：McGee 提供烹饪现象与操作解释，Food Chemistry 提供化学机制；不得把 2009 年教材中的条件直接变成通用配方。
- 与 `FB-PAGE-2008`：McGee 解释加热和结构，Flavor Bible 提供搭配线索；搭配线索不是实验证明。
- 与 `CR-WXY-2003`：McGee 解释“为什么”，烹饪原料学补充分类、品质、保藏与原料应用。
- 与第一阶段四书：食材感官与本草内容仍分别引用原来源，不把《食物与厨艺》当成本草或医疗证据。

## 5. OCR 质量与使用边界

知识片段按置信度统计：

| 卷册 | low | medium | high |
|---|---:|---:|---:|
| 卷一 | 35 | 361 | 0 |
| 卷二 | 205 | 203 | 0 |
| 卷三 | 163 | 252 | 0 |

这是扫描书，页面记录通常为 `medium` 或 `low`。`low` 只能作为检索线索，不能单独支撑温度、比例、时间、化学式或安全性结论。所有扫描页引文应：

- 尽量短，避免把整段 OCR 噪声当成原文；
- 保留 `confidence`；
- 在关键数字、单位、否定词和条件从句上回看原页；
- 无法辨认时写 `[知识库缺口]`，不要根据上下文猜测补字。
