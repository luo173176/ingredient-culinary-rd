# 工作流 08 · 专题研究报告

## 目的

把一个开放问题做成可复核的研究报告：问题清楚、检索可复现、证据分级、冲突保留、假设可检验。

## 触发

- “帮我做一个关于 XX 的专题研究”
- “十本书里关于 XX 怎么说”
- “设计一个实验验证 XX”
- “写一份食材研究报告”

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| 研究问题 | 是 | 越具体越好；避免“XX 好不好” |
| 范围 | 否 | 限定食材/菜系/人群/工艺 |
| 产出 | 否 | 综述/对比/实验设计/教学材料 |

## 步骤

### 1. 问题拆解

把大问题拆成 3–6 个子问题，每个子问题对应可检索的关键词。

### 2. 检索策略

记录每次查询：query、source filter、命中数、采用/排除理由。至少覆盖 3 本书。

### 3. 证据分级

| 级别 | 含义 |
|---|---|
| A | 原文直接陈述，页码可核 |
| B | 两本以上书一致，或可复现的跨来源推理 |
| C | 单一来源/OCR 低置信/推测 |
| D | 知识库缺口 |

### 4. 交叉验证

对每个核心观点做“支持/反驳/不相关”三栏；不要只找支持证据。

### 5. 冲突保留

不同书不一致时并列，写清各自页码；不强行调和。

### 6. 假设与实验

假设必须可证伪；实验必须有变量、对照、指标、样本量、记录表。

### 7. 结论分级

每个结论标 A/B/C/D，并说明证据。

## 质量检查

- [ ] 检索策略可被第三方复现。
- [ ] 每个结论有级别。
- [ ] 有反驳证据栏。
- [ ] 冲突没有被“平均掉”。
- [ ] 没有真实实验就写“未验证”。
- [ ] 引用的页码在索引中真实存在。

## 安全边界

涉及医疗、药理、毒理时，明确“十书不含完整临床证据/现代毒理数据”，不给出治疗建议。

## Phase 2 研究增强

### 来源矩阵

| 研究子问题 | 主来源 | 辅助来源 |
|---|---|---|
| 食材分类、品质、保藏 | `CR-WXY-2003` | 第一阶段食材书 |
| 受热、结构、加工现象 | `MCG-V1/V2/V3` | Food Chemistry |
| 化学机制与反应 | `FC-BELITZ-2009` | 对应烹饪科学卷册 |
| 搭配候选 | `FB-PAGE-2008` | Food Chemistry 香气机制 |
| 盐脂酸热操作 | `FS-SFAH-2023` | 菜谱与食材书 |
| 传统本草 | `MM-ZYX-2016` | 不使用食品化学替代理论 |

### 多书交叉验证表

| 观点 | 支持来源 | 反驳/限制 | 证据等级 | 判定 |
|---|---|---|---|---|
| … | E1/E2 | E3/low conf | A/B/C/D | 支持/部分支持/无法判定 |

### 实验设计最低要求

- 明确自变量、因变量、对照；
- 固定原料、批次、切割、设备预热；
- 记录真实温度、时间、重量、pH/水分活度（如有）；
- 感官评价至少给评分维度、量表、盲评方式和人数；
- 保存试验必须区分感官变化与微生物风险；
- 没有实验数据就写：

```text
validation_status: designed_only
```

### 检索示例

```bash

python scripts/search.py "盐 渗透 扩散" --source FS-SFAH-2023
```
