# 工作流 04 · 风味科学分析

## 目的

用盐、脂、酸、热解释“为什么好吃/为什么不好吃”，并给出可操作的修正路径。

## 触发

- “为什么这道菜不香/太咸/太腻/太酸/发苦”
- “怎么让味道更有层次”
- “盐脂酸热怎么平衡”
- “这个做法背后的原理”

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| 菜品/配方 | 是 | 尽量有用量与步骤 |
| 问题 | 是 | 太咸、太淡、腻、酸、涩、柴、腥、不香等 |
| 设备 | 否 | 灶具、烤箱、温度计 |

## 四维诊断

### 盐

- 是否提前加盐？渗透是否完成？
- 盐量相对于总重量、含水量、淀粉/蛋白质含量是否合理？
- 盐是否只在表面，没有进入结构？

### 脂

- 脂肪类型、用量、乳化状态、温度。
- 是否用脂肪承载香气？是否过度导致腻？
- 脂水比例与口感。

### 酸

- 酸的种类（柠檬/醋/发酵酸/番茄）、添加时点、受热损失。
- 酸是否平衡了脂肪、甜、咸、苦？
- 酸是否让蛋白质过度收紧？

### 热

- 传热方式（传导/对流/辐射）、温度、时间、含水率、表面积。
- 是否发生美拉德/焦糖化/蛋白质变性/淀粉糊化？
- 是否“外熟内生”或“过度脱水”？

## 检索计划

1. 先按问题词检索《盐，脂，酸，热》：盐与风味、盐分扩散、油脂与风味、酸与风味、热与烹饪。
2. 再按食材检索《DK食材百科全书》《中国地道食材图录大全》的质地与处理。
3. 需要传统属性时再查《中药学》，但不作为风味因果证据。

## 步骤

### 1. 描述现象

不写“不好吃”，写“入口咸感集中在前端、后味发苦、肉质干柴、香气弱”。

### 2. 归因

每个现象给 1–3 个候选原因，按可能性排序，标 `[原文]` 或 `[跨来源推理]`。

### 3. 设计修正

每个修正给：

- 动作
- 用量/温度/时间
- 预期变化
- 风险（过量、不可逆）

### 4. 给“最小改动”方案

先改 1 个变量，再改第二个；不要一次加五种调料。

## 质量检查

- [ ] 现象与归因分开。
- [ ] 没有把“盐能提鲜”绝对化。
- [ ] 温度/时间有单位。
- [ ] 修正方案是最小改动，不是重做一道菜。
- [ ] 引用了《盐，脂，酸，热》的具体页。

## 安全边界

涉及油炸、压力锅、明火、酒精时提示操作风险；不提供危险的高温/高压“技巧”。

## Phase 2 机制增强

### 五书联合诊断

复杂风味问题至少按需调用：

| 问题 | 来源 |
|---|---|
| 盐、脂、酸、热的烹饪平衡 | `FS-SFAH-2023` |
| 食材结构与加热变化 | 对应《食物与厨艺》卷册 |
| 化学机制与条件 | `FC-BELITZ-2009` |
| 搭配候选 | `FB-PAGE-2008` |
| 原料品质、加工与保藏 | `CR-WXY-2003` |
| 产地、品种、感官 | 第一阶段食材书 |

### 常见现象到机制

| 现象 | 先查 | 再查 |
|---|---|---|
| 肉变干、收缩 | 肌肉蛋白/变性 | 《食物与厨艺》肉类章 |
| 酱汁稀、结块 | 淀粉糊化 | 卷一酱料章 |
| 酱汁分层 | 乳化/脂水界面 | Food Chemistry 脂质及乳状液 |
| 表面褐变、香气 | 美拉德反应 | 卷一烘焙/卷三烹调原理 |
| 油脂哈喇味 | 脂质氧化 | Food Chemistry 脂质章 |
| 香气弱 | 香气阈值/挥发 | 食品化学香气章 + 搭配条目 |
