# 模块 B-2 · 全球食材（DK）

## 来源

《食材百科全书》（英国DK出版社，丛龙岩译，中国轻工业出版社）。扫描版 OCR。

## 覆盖

按书的章节组织：鱼类和贝类海鲜、肉类、家禽类以及野味类、蔬菜类、香草类、香料类、乳制品和蛋类、水果类、坚果和种子类、谷物类、大米类、意大利面以及面条类、油脂类、醋类、调味品类。

## 使用方式

1. 先读 `index.md` 找食材与页。
2. 卡片在 `ingredients/*.md`。
3. 书里的“搭配各种风味 / 经典食谱 / 食用 / 加热烹调 / 切制”是主要字段。
4. OCR 多栏页面可能串行；引用短句前回看页面图像。

## 注意

- 这本书是翻译版，英文名/学名可能被 OCR 破坏；不确定就不写学名。
- 书里的品种名、产地、季节以原书为准，不补外部资料。
- 鱼类/贝类要提示过敏原、生食风险、来源可持续性（书中有提及时才写）。
