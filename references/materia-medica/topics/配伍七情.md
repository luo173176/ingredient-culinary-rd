# 配伍七情

> 来源：《中药学》第五章 中药的配伍（PDF 124–126）。
> 性质：传统中医药配伍理论；不是现代药物相互作用数据库。

## 一句话

七情是单味药应用与药与药之间关系的七种概括：单行、相须、相使、相畏、相杀、相恶、相反。

## 原文要点

| 编号 | 要点 | 出处 |
|---|---|---|
| E1 | 七情包括单行、相须、相使、相畏、相杀、相恶、相反 | 《中药学》PDF 124 |
| E2 | 单行：单用一味药治疗病情单一的疾病 | 《中药学》PDF 124 |
| E3 | 相须：性能功效类似的两药配合，增强原有功效；如麻黄配桂枝 | 《中药学》PDF 124 |
| E4 | 相使：性能有共性或治疗目的一致，一主一辅，辅药提高主药功效；如黄芪配茯苓 | 《中药学》PDF 125 |
| E5 | 相畏：一药的毒性/副作用被另一药降低或消除；如半夏畏生姜 | 《中药学》PDF 125 |
| E6 | 相杀：一药能降低/消除另一药的毒性或副作用；与相畏是同一关系的两种提法 | 《中药学》PDF 125 |
| E7 | 相恶：一药使另一药原有功效降低甚至丧失；如人参恶莱菔子 | 《中药学》PDF 125 |
| E8 | 相反：两药同用产生或增强毒性/副作用；如甘草反甘遂、贝母反乌头 | 《中药学》PDF 125 |

## 关系表

| 关系 | 方向 | 结果 | 传统用法 |
|---|---|---|---|
| 单行 | 单药 | 单味治疗 | 病情单纯 |
| 相须 | 同类 | 增效 | 常用 |
| 相使 | 主辅 | 辅药增效 | 常用 |
| 相畏 | A 的毒/副作用被 B 制 | 减毒 | 炮制/配伍 |
| 相杀 | B 制 A 的毒/副作用 | 减毒 | 同上 |
| 相恶 | A 的功效被 B 削弱 | 减效 | 避免 |
| 相反 | A+B | 增毒/副作用 | 禁忌 |

## 对烹饪配伍的用法

`[跨来源推理]` 烹饪搭配可以借用“相须/相使”的语言描述风味协同，但必须标明这是比喻，不是药效结论。

```text
[烹饪·跨来源推理] 花椒的麻香与辣椒的辣感在感官上互相放大，可类比“相须”，但这不是中药配伍意义上的增效。
[本草·原文] 相须是“两种性能功效类似的中药配合应用，可以增强原有药物的功效”（《中药学》PDF 124）。
```

## 安全红线

- 不得根据七情给用户开方。
- 不得把“相畏/相杀”写成“可以互相解毒，所以放心同吃”。
- 十八反、十九畏的具体药对见 `用药禁忌.md`；仍需专业判断，不能自行尝试。
- 烹饪里“相克”的说法，不能包装成现代医学事实。
