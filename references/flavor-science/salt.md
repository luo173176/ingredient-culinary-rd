# 盐

> 来源：《盐，脂，酸，热》第一章 盐（PDF 19–49）。
> 说明：以下为原书烹饪原理与作者经验，不是食品工业标准。

## 一句话

盐是影响食物风味最大的单一因素；它既提供咸味，也通过渗透、扩散、蛋白质改性和抑制苦味来改变味道与质地。

## 机制拆解

```text
盐
├─ 味道：咸味、抑苦、平衡甜、托香
├─ 物理：渗透（水出）→ 扩散（盐入）→ 平衡
├─ 蛋白质：部分溶解/改性 → 保水、嫩度、容错
├─ 表面：盐粒口感、脆感、视觉
└─ 时间：提前量决定均匀度；过量/过久→脱水、腌渍
```

## 对菜谱研发的用法

1. **先问时间**：这块肉/菜从加盐到入口有多久？
2. **再问形态**：盐粒粗细、密度、是否溶解。
3. **再问目标**：要咸味、要嫩、要脆、要抑苦，还是只要表面口感？
4. **最后定量**：按总重百分比记录，并给品尝修正。

写作示例：

```text
[原文] 作者经验：肉类、蔬菜、谷物按总重 1% 加盐；煮面水 2%（PDF 39）。
[跨来源推理] 本菜谱总重约 800 g，1% 为 8 g；但盐的密度不同，必须称重，不能按“一勺”估。
[创新假设] 若提前 12 h 干盐腌鸡腿，可能比临煎前撒盐更均匀、更多汁；需对照试验验证。
```

## 常见误区

- “盐只会变咸”——忽略了抑苦、平衡甜、托香、保水。
- “腌肉越久越咸越好”——过久会脱水、腌渍化。
- “一勺盐等于固定克数”——不同盐密度差异很大。
- “低钠盐可以随便多吃”——本知识库没有低钠盐/钾盐的充分依据，标缺口。

## 安全与限制

- 1% / 2% 是作者经验值，不是所有人的健康推荐量。
- 高血压、肾病、心衰等人群应遵医嘱；本 Skill 不给个体化限盐处方。
- 腌制/卤水涉及微生物风险，需冷藏与时间控制；四书未覆盖的具体安全限量标缺口。
