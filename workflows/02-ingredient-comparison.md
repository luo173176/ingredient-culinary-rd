# 工作流 02 · 食材对比研究

## 目的

回答“有什么不同、能不能换、换了会怎样”，而不是各写一段百科。

## 触发

- “A 和 B 有什么区别”
- “没有 A 能不能用 B”
- “哪种更适合做 XX”
- “同一食材不同品种/产地/成熟度对比”

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| 对比对象 | 是 | 2–4 个；超过 4 个先分组 |
| 对比维度 | 否 | 默认：分类、产地、季节、香气、味道、口感、烹饪、替代、安全 |
| 使用场景 | 否 | 决定哪个维度权重更高 |

## 检索计划

1. 分别检索每个对象，保证证据量平衡（不要一个 8 条、一个 1 条）。
2. 补检“替代/相似/区别/相比之下”等关系词。
3. 对每个维度做**同维度对齐**，没有证据的格子写“—（无依据）”。
4. 至少找 1 条“不能互换”的理由；找不到就写“现有四书不足以判断”。

## 步骤

### 1. 建对比矩阵

| 维度 | A | B | 依据 |
|---|---|---|---|
| 分类 | | | E1/E2 |
| 主产地 | | | |
| 季节 | | | |
| 香气 | | | |
| 味道 | | | |
| 口感 | | | |
| 适合做法 | | | |
| 不适合做法 | | | |
| 安全/禁忌 | | | |

### 2. 写“关键差异”三条

只写会改变烹饪决策的差异，例如水分、纤维、酸度、脂肪、香气挥发性、耐热性。

### 3. 给替代结论

分三档：

- **可直接替代**：证据支持风味/质地接近，给出替换比例范围（有依据才写）。
- **有条件替代**：说明会损失什么、需要补什么。
- **不建议替代**：说明原因（安全、结构、风味不可逆）。

### 4. 冲突处理

同一维度不同书说法不同 → 并列，不投票。

## 输出模板

```markdown
# {A} vs {B}

## 结论（先给能不能换）
...

## 对比矩阵
| 维度 | A | B | 证据 |
|---|---|---|---|

## 三条关键差异
1. ...
2. ...
3. ...

## 替代方案
### 可直接替代
### 有条件替代
### 不建议替代

## 场景建议
- 做 X：选 …
- 做 Y：选 …

## 证据表
## 知识缺口
```

## 质量检查

- [ ] 每个对象证据量大致平衡。
- [ ] 没有把“不同”写成“谁更好”。
- [ ] 替代结论有条件、有代价。
- [ ] 安全差异单列（过敏原、毒性、生食风险）。

## 安全边界

不要根据“性味相近”就判断可以互换，尤其涉及药材、孕妇、慢病人群。
