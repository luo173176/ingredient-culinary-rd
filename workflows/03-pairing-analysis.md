# 工作流 03 · 食材配伍分析

## 目的

分析“能不能搭、为什么搭、搭了有什么风险”。同时处理**烹饪搭配**与**传统本草配伍**，两者必须分开。

## 触发

- “A 和 B 能一起吃吗”
- “这个食疗方合理吗”
- “药食同源怎么配”
- “XX 和 XX 相克吗”

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| 食材/药材清单 | 是 | 2–8 味；超过 8 味先拆方 |
| 人群 | 否 | 孕妇、儿童、老人、慢病、用药 |
| 目的 | 否 | 日常菜/食疗/研发 |

## 两条分析线（必须分开写）

### 线 1：烹饪搭配

看：香气同频/互补、酸甜苦咸鲜平衡、脂肪与酸、质地对比、成熟度、含水率、受热行为。

### 线 2：传统本草配伍

看：《中药学》的七情（单行、相须、相使、相畏、相杀、相恶、相反）、十八反、十九畏、妊娠禁忌、证候禁忌。

> 传统配伍理论不等于现代药物相互作用证据；不得据此给用户开方。

## 检索计划

1. 每味食材/药材单独检索（性味、功效、禁忌）。
2. 检索“配伍/相须/相使/相畏/相杀/相恶/相反/十八反/十九畏/妊娠禁忌”。
3. 检索组合名或经典方名（如果用户给了）。
4. 检索食品安全词：过敏原、生食、亚硝酸盐、组胺、毒性。

## 步骤

### 1. 列出每味的作用角色

主料 / 辅料 / 香气 / 酸 / 脂 / 质地 / 药性角色。

### 2. 做“相加/相减/相乘/相杀”表

| 组合 | 烹饪效果 | 传统理论关系 | 风险 | 依据 |
|---|---|---|---|---|

“相乘”只用于风味放大，不写“药效增强”。

### 3. 找冲突

- 传统禁忌：十八反、十九畏、妊娠禁忌、证候禁忌。
- 现代食品安全：过敏、毒性、微生物、亚硝酸盐、药物相互作用（四书没有就标缺口）。

### 4. 给结论

四档：

- 推荐搭配（烹饪证据充分，安全）
- 可用但有条件
- 不建议同用（明确禁忌/风险）
- 现有四书不足以判断

## 输出模板

```markdown
# {组合} 配伍分析

## 结论
...

## 1. 角色分工
## 2. 烹饪层面的搭配
## 3. 传统本草层面的配伍
> 传统理论，不是现代医学证据。
## 4. 冲突与风险
## 5. 可用方案（含用量范围/替代）
## 6. 不适用人群
## 证据表
## 知识缺口
```

## 质量检查

- [ ] 烹饪线与本草线没有混成一段。
- [ ] 没有把“相克”当成现代医学事实。
- [ ] 没有给个体化处方/剂量。
- [ ] 有毒药材单独警示。
- [ ] 过敏原与特殊人群写清楚。

## 安全边界

涉及附子、川乌、草乌、半夏、天南星、马钱子、巴豆、甘遂、芫花、斑蝥、雄黄、朱砂等，直接标“不可作为日常食材”，只做知识说明。
