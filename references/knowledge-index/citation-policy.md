# 引用与诚实性政策

本文件是 Skill 的“引用宪法”。任何回答、卡片、报告都按此执行。

## 1. 唯一允许的事实来源

| source_id | 书名 | 用途 |
|---|---|---|
| `MM-ZYX-2016` | 《中药学》第4版 | 本草理论、单味药性味功效应用禁忌 |
| `CN-DIDAO-2011` | 《中国地道食材图录大全》 | 中国食材、产地、时令、品种、食疗 |
| `FS-SFAH-2023` | 《盐，脂，酸，热》 | 盐脂酸热原理、烹饪方法 |
| `DK-INGREDIENTS` | 《食材百科全书》 | 全球食材、品种、风味搭配、处理 |

四书之外的内容：

> 当前四本书知识库暂无充分依据。

这句话可以展开说明“已检索哪些书、哪些关键词”，但不能用外部知识补成结论。

## 2. 页码规则

### 2.1 两个页码字段

- `printed_page`：书页上实际印刷的页码。只有在页眉/页脚直接看到数字时才填写。
- `pdf_page`：PDF 文件中的物理页序号，从 1 开始。

### 2.2 引用写法

```text
《中国地道食材图录大全》p.37（PDF 40）
《中药学》PDF 396
《盐，脂，酸，热》PDF 31
《食材百科全书》p.136（PDF 40）
```

- 数字版 calibre PDF 没有印刷页码，写 `PDF 396`，不得写 `p.396`。
- 扫描书识别到页脚数字，写 `p.37（PDF 40）`。
- 识别不到，只写 `PDF 40`，不得按“偏移 3 页”推算。

### 2.3 只有章节没有页

```text
相关章节：《中药学》第十四章 温里药；未能定位到具体页码。
```

## 3. 四类陈述

### `[原文]`

- 直接引用：加引号，不超过 120 字；长段用忠实摘要。
- 必须给 E 编号。
- OCR 页面标 `conf`；`low` 不作为关键结论的唯一依据。

### `[跨来源推理]`

- 至少两个来源，或同一来源两个独立段落。
- 写推理链：`E1 说 A；E2 说 B；因此 A+B 在 C 条件下可能……`
- 不得写成“书上说”。

### `[创新假设]`

- 写“假设”“待验证”“预测”。
- 给验证方法：变量、对照、指标。
- 不得写成“已经验证/效果最好”。

### `[知识库缺口]`

固定句式：

> 当前四本书知识库暂无充分依据。

可补充：缺的是哪个维度（产地/品种/温度/毒性/临床证据），已检索哪些关键词。

## 4. 冲突处理

不同书对同一对象说法不一致：

```markdown
**来源冲突：花椒的主产地**
- 《中药学》PDF 396：主产于辽宁、河北、四川，传统以四川产者为佳。［E1］
- 《中国地道食材图录大全》p.xxx：……［E2］
- 处理：并列保留。现有四书不足以判断哪一说法覆盖所有品种/年代。
```

禁止：

- 取“多数票”。
- 把两个产地合并成“主产于 A、B、C、D”。
- 用模型记忆判定谁对。

## 5. OCR 可信度

| 等级 | 条件 | 用法 |
|---|---|---|
| high | 文本层，或 OCR 平均分 ≥ 0.72 且低置信行 < 25% | 可引用 |
| medium | OCR 平均分 0.72–0.80，偶有错字 | 可引用，关键句回看图像 |
| low | 平均分 < 0.72 或大量低置信行 | 只作检索线索，不单独支撑结论 |

页面记录里的 `warnings` 必须一起看。常见警告：

- `ocr_many_low_confidence_lines`
- `ocr_low_mean_confidence`
- `ocr_sparse_text`
- `no_text_detected`

## 6. 传统理论与现代证据

- 性味、归经、功效、配伍、禁忌：传统中医药理论。
- 化学成分、药理作用、不良反应：教材“现代研究”栏目，属于教材转述，不等于临床指南。
- 不能写“某食材能治疗/治愈/替代药物”。
- 不能把动物实验/体外实验写成人体结论。

## 7. 安全表述

必须出现（按题目相关）：

- “以下为传统理论，不是现代医学疗效证据。”
- “教材用法用量仅为原文信息，不构成个体用药建议。”
- “孕妇、哺乳期、儿童、肝肾功能不全、正在服药者请先咨询医生/药师。”
- “有毒药材不可作为日常食材。”

## 8. 引用自检

交付前逐条核对：

1. `source_id` 是否存在。
2. `pdf_page` 是否在该书页数范围内。
3. 引用文字是否真的出现在该页（用 `search.py --page` 回查）。
4. `printed_page` 是否与页脚一致。
5. 章节名是否来自 TOC 或页面标题，不是编的。
6. 每个 `[原文]` 是否有 E 编号。
7. 每个 `[跨来源推理]` 是否至少两个来源。

机器辅助：

```bash
python scripts/validate_output.py answer.md
```
