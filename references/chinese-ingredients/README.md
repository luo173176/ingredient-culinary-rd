# 模块 B-1 · 中国地道食材

## 来源

《中国地道食材图录大全》（李清，武汉出版社，2011）。扫描版 OCR，页脚可见印刷页码时保留 `p.X（PDF Y）`。

## 覆盖

按书的结构分为八章：

1. 谷物和米面制品
2. 乳制品和蛋
3. 蔬菜
4. 水果
5. 坚果
6. 肉
7. 鱼虾蟹贝
8. 调味品

## 使用方式

1. 先读 `index.md` 找食材所在章与页。
2. 再读 `ingredients/*.md` 的卡片；没有卡片就用 `search.py` 检索原书页。
3. 这本书的版式复杂，OCR 文本可能串行；**引用具体句子前回看页面图像**。
4. 书里的“性味/功效/食疗”属于传统饮食经验，不是现代营养学结论。

## 卡片字段

每张卡按统一食材模型写：别名、分类、产地、品种、季节、品质、香气、味道、口感、本草属性（如有）、烹饪、搭配、替代、保存、安全、来源。

## 注意

- 这本书有不少“食疗心经/药膳”内容，必须标注“传统饮食经验”，不得写成治疗建议。
- OCR 会把“，”识别成“’”“°”，引用时保留原样或做最小清理，不改变语义。
- 页码：以页脚可见数字为 `printed_page`；没有识别到就只写 PDF 页。
