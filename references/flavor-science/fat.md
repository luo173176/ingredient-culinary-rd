# 脂

> 来源：《盐，脂，酸，热》第二章 脂（PDF 50–82）。
> 说明：原书讲油脂的风味、质地与烹饪作用；不是油脂营养学指南。

## 一句话

油脂是风味载体、传热介质和质地塑造者；它能延长香气与味觉的停留，并通过高温促进褐变。

## 机制拆解

```text
脂
├─ 风味：溶解/承载香气，延长停留
├─ 传热：高沸点，煎炸上色
├─ 质地：脆、酥、软、滑、蓬松
├─ 乳化：油+水+乳化剂（蛋黄、芥末、蛋白质）
└─ 温度：固态/液态/烟点/分离
```

## 对菜谱研发的用法

1. **选脂**：要中性传热、要香气、要乳化、要起酥，目的不同。
2. **定量**：脂肪不是越多越香；过量会腻、压香、影响乳化。
3. **控温**：煎炸要区分“下锅温度”和“持续温度”；黄油易焦，可混少量中性油。
4. **乳化**：油醋汁先加芥末/蛋黄，再缓慢加油；分离时可加几滴水或酸重新搅。
5. **补香**：香料/香草可先在油中低温浸出，再用于主食材。

## 常见误区

- “油温越高越香”——超过烟点会产生异味与有害物；四书没有给出各油烟的精确温度表，标缺口。
- “黄油更健康/更香”——本书只谈风味与质地，不做营养优劣判断。
- “油醋汁摇一摇就稳定”——没有乳化剂会很快分层。
- “减脂就是少放油”——可能同时损失香气、传热与质地，需要替代设计。

## 安全与限制

- 油炸需控制油温、避免反复使用；具体烟点/极性组分限量标缺口。
- 油脂过敏/乳制品过敏需点名。
- 不把“好脂肪”写成疾病预防结论。
