# 模块 C · 风味科学

## 来源

《盐，脂，酸，热：制造美味的新科学》（萨明·诺斯拉特，靳婷婷译，中信出版社，2023）。

## 四个核心维度

| 维度 | 核心问题 | 卡片 |
|---|---|---|
| 盐 | 咸味、渗透、蛋白质、提前调味 | `salt.md` |
| 脂 | 香气载体、传热、乳化、口感 | `fat.md` |
| 酸 | 平衡、提亮、蛋白质收紧、受热 | `acid.md` |
| 热 | 传热方式、温度、时间、美拉德/焦糖化 | `heat.md` |

综合平衡：`balance.md`。

## 使用方式

1. 先描述现象（咸、腻、酸、柴、不香），不要先猜原因。
2. 四维各问 2–3 个问题。
3. 每个归因给证据；没有证据的写“假设”。
4. 修正方案一次只改 1–2 个变量。
5. 用“下一轮验证”收尾：变量、对照、判断标准。

## 重要限制

- 这本书讲的是烹饪原理与经验，不是食品工程参数手册。
- 书中的温度/时间是作者经验，实际要按设备、食材厚度调整。
- 不把“盐能提鲜”绝对化；过量盐仍是健康风险。
