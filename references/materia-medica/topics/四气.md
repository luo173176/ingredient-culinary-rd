# 四气（四性）

> 来源：《中药学》第四章 中药的性能 · 第一节 四气（PDF 100–101）。
> 性质：传统中医药理论，不是现代医学疗效证据。

## 一句话

四气是药物作用于人体后表现出的寒、热、温、凉四种药性倾向；寒凉属阴，温热属阳，平性药寒热界限不明显。

## 原文要点

| 编号 | 要点 | 出处 |
|---|---|---|
| E1 | “四气，就是寒热温凉四种不同的药性，又称四性。” | 《中药学》PDF 100 |
| E2 | “寒凉属阴，温热属阳”；“凉次于寒”“温次于热” | 《中药学》PDF 100 |
| E3 | 平性药“寒热界限不很明显、药性平和、作用缓和”，如党参、山药、甘草 | 《中药学》PDF 100 |
| E4 | 药性由“药物作用于人体所产生的不同反应和所获得的不同疗效”总结；能减轻/消除热证者多属寒凉，反之多属温热 | 《中药学》PDF 100 |
| E5 | 寒凉药多清热泻火、凉血解毒等，用于阳热证；温热药多温里散寒、补火助阳等，用于阴寒证 | 《中药学》PDF 101 |
| E6 | “寒者热之，热者寒之”；“疗寒以热药，疗热以寒药” | 《中药学》PDF 101 |

## 结构

```text
四气
├─ 寒（阴）── 凉（次于寒）
├─ 热（阳）── 温（次于热）
└─ 平（寒热界限不明显；是否独立成“性”有争议）
```

## 对食材研究的用法

`[跨来源推理]` 在食材卡里，“性寒/性凉/性温/性热/性平”只能作为**传统属性**单列，不能直接推导出现代营养学结论，也不能据此判断“什么人一定不能吃”。

可这样写：

```text
传统属性：味甘，性凉（《中药学》PDF xxx）。
现代营养/食品安全：当前四本书知识库暂无充分依据/见 DK 页 xxx。
```

## 常见误用

- 把“性寒”写成“会伤胃/导致腹泻”的确定医学结论。
- 把“性温”写成“能治宫寒/阳痿”。
- 用四气替代过敏、微生物、剂量等现代食品安全判断。
- 把平性药当成“人人适合、可长期大量吃”。
